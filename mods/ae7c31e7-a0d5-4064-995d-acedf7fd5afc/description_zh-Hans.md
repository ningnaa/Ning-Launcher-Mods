# Player Ping UI

在多人游戏中显示你的延迟，并可打开一个面板查看每位已连接玩家的延迟。

## 使用方法

- 多人游戏中，延迟指示器位于**生命条旁边**，在其左端并与其居中对齐：图标随连接状况变化（满、中、低、空），下方的毫秒数从绿色变为红色。
- 在模组配置中关闭**显示在生命条旁边**即可随意放置：此时可以用手指**拖动**它。
- **点击**指示器可打开设置：图标样式以及每隔几秒测量一次延迟。
- 延迟图标旁边的**玩家面板**按钮会在其下方打开服务器面板：显示每位玩家的头像、名字、延迟和所选图标。
- 单人游戏中不会显示任何内容。

延迟是真实测量的：设备向服务器发送一个数据包，并计时其返回所需的时间。你选择的图标样式会在服务器面板中对所有人显示。

## 样式

紫色、基础、Nintendo DSi、金色、浅色基础、华丽金色和 Minecraft。也可以在模组配置中更改，同时还有隐藏指示器的选项。

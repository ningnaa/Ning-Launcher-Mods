# SilkyUI

供更好的体验等模组使用的界面前置库，提供布局、控件和绘制接口。

适用于柠版泰拉启动器 0.5.1（410）与 Terraria Build 1720。

太阳照常升起（原模组作者）、柠版泰拉启动器（移动版汉化与维护）。

### 0.3.0-r.2 更新

关闭的面板暂不插入游戏绘制图层，无需切换绘制批次。打开后按原有顺序绘制。

此版本适用于柠版泰拉启动器 0.5.4.3（415）和 Terraria Build 1720。

### 0.3.0-r.3 更新

修复裁剪面板合成时绘制批次尚未开启，导致面板渲染中断的问题。

适用于 Terraria Build 1720。

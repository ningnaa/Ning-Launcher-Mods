# 更好的体验

提供储存管理器、钓鱼机、药水袋、旗帜盒和多种建造工具。部分功能需在模组配置中开启。需要配套的 SilkyUI。

## 本版修复

修复手持其他模组物品时放置加速黑名单查找报错，以及配置页拼音搜索无法使用的问题。

适用于柠版泰拉启动器 0.5.2（411）及 Terraria Build 1720。需要 SilkyUI。

# 更好的体验

**重要：本模组为测试版，可能闪退。**

提供储存管理器、钓鱼机、药水袋、旗帜盒和多种建造工具。部分功能可在模组配置中开启。

- 修复弹药链触屏编辑、取消编辑时串改配置，以及弹药链不同的武器错误合堆。
- 修复药水袋和旗帜盒的触屏存取、容量检查与联机设置同步。自动收纳和合成扣料现在会同步至对端。
- 修复大型容器和超级背包在加入联机时数据不完整的问题，保留 JS 物品的独立自定义状态。

适用于柠版泰拉启动器 0.5.4.3（415）及 Terraria Build 1720，需要 SilkyUI。涉及大容器的联机请让所有玩家使用相同的启动器与模组版本。测试版仍可能出现闪退。

# 掉落光柱（C#）

按掉落物稀有度、价值和配置名单显示光柱、光晕与颜色。可关闭叠加绘制。

## 掉落光柱（C#） 1.9.4.5-r.2（2026-11-21）

- 修复为 JS 模组掉落物绘制光柱时查找物品编号报错。颜色、允许名单和屏蔽名单按稳定物品名称匹配。
- 适用于柠版泰拉启动器 0.5.4 和 Terraria Build 1720。与同功能 JS 版可按需选用。

原模组作者为 ChemAtDark。移动版汉化与维护为柠版泰拉启动器。

### 1.9.4.5-r.3 更新

有实际掉落物时才初始化并更新光柱状态。拾取后再次掉落会重新播放渐入动画。

此版本适用于柠版泰拉启动器 0.5.4.3（415）和 Terraria Build 1720。

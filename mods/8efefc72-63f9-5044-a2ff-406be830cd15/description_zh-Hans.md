# 魔法存储

用存储核心和存储单元集中管理物品，并通过制作界面查询和制作配方。需要 absoluteAquarian Utilities。

适用于柠版泰拉启动器 0.5.1（410）与 Terraria Build 1720。需要 absoluteAquarian Utilities。

absoluteAquarian & Contributors（原模组作者）、柠版泰拉启动器（移动版汉化与维护）、Bloa（JS 版移动界面参考）、Titan camera（JS 版移植与界面参考）。

## 本版修复

储存面板或使用指南失去绘制权限时会正常关闭。关闭储存面板后恢复启动器按钮，并可再次打开。 弹窗关闭后恢复游戏界面需搭配柠版泰拉启动器 0.5.2（411）或更新版本。适用 Terraria Build 1720。 需要 absoluteAquarian Utilities。

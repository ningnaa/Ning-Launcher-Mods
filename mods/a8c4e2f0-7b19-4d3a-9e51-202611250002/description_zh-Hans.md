# 万象奥术 · 法师军械库

收录从开荒到月亮领主之后的九把法器，包括符文引爆、棱镜折射和奇点权杖。手持相应法器时可用其触控副技。

适用于 Terraria Build 1720。需要支持 C# 模组的柠版泰拉启动器。

制作人员：力力丝（策划构想与监制）、哈基米（主制作与代码实现）。许可：CC-BY-NC-4.0。

## 作者说明

# 万象奥术 · 法师军械库 (`arcanearsenal`)

> **全时期 9 把机制迥异的高阶法器，重塑泰拉瑞亚 PE 端法师战斗体验！**

告别单调的线性换皮法杖——从肉前开荒到月球领主之后，每一个游戏阶段都拥有 **独立获取、专属待机/收刀/施法动作组、多帧动态贴图与动态图标触控副技** 的全新法器！

---

## 核心特色

- **专属武器动作组**：法杖待机镜像斜背身后、蚀骨符文笔缩放悬于肩后、棱镜/星仪/真理魔典环绕护主，转身与施法过渡自然丝滑。
- **动态触控副技按键**：游戏内触控副技按钮图标随当前手持武器自动实时切换，直观显示技能状态、计数与冷却进度。
- **PE 端深度性能优化**：全弹幕采用单次零内存分配速度流光拖尾与本地纹理指针缓存，兼顾炫酷视觉表现与高帧率流畅战斗。

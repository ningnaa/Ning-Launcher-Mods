# 召唤师扩展

为召唤师补充3件新装备，并为原版史莱姆法杖增加前期配方。原作者：YG；移植者：逐邺。保留源包的MIT许可声明。

## 星之庇佑

在工作台用1颗坠落之星制作。装备后基础增加1个召唤栏位、1个哨兵栏位、10%召唤伤害及30%移动速度。

饰品读取当前世界的Boss击败进度，分为以下9组；每组任意一名Boss被击败即获得该组奖励，同组不会重复叠加：

1. 史莱姆王 / 克苏鲁之眼
2. 世界吞噬怪 / 克苏鲁之脑
3. 蜂王 / 骷髅王 / 独眼巨鹿
4. 血肉墙（进入困难模式）
5. 史莱姆皇后 / 任意机械Boss / 猪龙鱼公爵
6. 世纪之花
7. 石巨人 / 光之女皇
8. 拜月教邪教徒
9. 月亮领主

全部9组完成时，饰品合计增加5个召唤栏位、5个哨兵栏位、100%召唤伤害、80点最大生命及16点防御。移动速度加成在进入困难模式后为50%，击败月亮领主后为100%。说明栏显示当前加成、完成组数和下一组的谜语提示。

成长取决于当前世界已有进度，换世界后按新世界计算；无需重复制作饰品。

## 史莱姆法杖配方

在工作台用15个凝胶制作原版史莱姆法杖。只增加配方，保留原版掉落。

## 小雪怪兜帽与靴子

| 装备 | 织布机配方 | 单件效果 |
|---|---|---|
| 小雪怪兜帽 | 6个小雪怪皮毛＋4个丝绸 | 1防御、5%召唤伤害 |
| 小雪怪靴子 | 8个小雪怪皮毛＋5个丝绸 | 1防御、5%召唤伤害、5%移动速度 |

两件新装备与原版小雪怪皮毛外套同时穿戴时，额外增加10%召唤伤害。套装额外奖励不再增加召唤栏位，原版外套自身的效果保留。

安装或更新后重启游戏。适用于本包声明的Terraria运行版本；联机兼容性尚未充分验证。

# 更好的体验

**重要：本模组为测试版，可能闪退。**

提供储存管理器、钓鱼机、药水袋、旗帜盒和多种建造工具。部分功能可在模组配置中开启。

### 1.8.2-r.6 更新

- 优化探测无人机的手持电台绘制。仅在手持且使用动画结束时绘制电台，减少日常角色渲染的额外开销。
- 减少机械蠕虫等多节 Boss 战斗中的弹幕命中检查。训练假人仍按实际近战和弹幕伤害统计。
- 药草加速和生命果生长规则按设置生效。生命果间距默认沿用原版规则，已设置的自定义间距继续生效。

### 此前更新

- 修复弹药链触屏编辑、取消编辑时串改配置，以及弹药链不同的武器错误合堆。
- 修复药水袋和旗帜盒的触屏存取、容量检查与联机设置同步。自动收纳和合成扣料现在会同步至对端。
- 修复大型容器和超级背包在加入联机时数据不完整的问题，保留 JS 物品的独立自定义状态。

适用于柠版泰拉启动器 0.5.4.3（415）及 Terraria Build 1720，需要 SilkyUI。涉及大容器的联机请让所有玩家使用相同的启动器与模组版本。测试版仍可能出现闪退。

### 1.8.2-r.7 更新

天气彩蛋只在播放期间监听 NPC 动画，训练假人存在时才启用命中统计和地图图标。减少界面和背包列表的每帧分配。

此版本适用于柠版泰拉启动器 0.5.4.3（415）和 Terraria Build 1720。 需要 SilkyUI。

# 成长型武器：渊海之息

包含星空、暗星、成长棱镜、深海剑和深渊法杖，支持进度成长、武器等级和专属技能。

【v2.1.0】
1.重置了暗星的武器贴图。
2. 全部武器配方改用代码名称引用（原初核心 / 坠落之星 / 铁锭组 / 水桶 /工作台），不再依赖硬编码 id，更新游戏后不会失效。
3. 所有 Leveled（真·）武器改为『原武器 + 原武器配方（去掉原初核心）』升级合成。
4. 补全暗星、星空的介绍与世界进度指引（tooltip）。
5. 深海剑统一为 DeepSea。

【内容】
一、神兵体系
1. 『星空』射手步枪：高射速高暴击，技能【日星隐曜】【黑洞】【白洞】【恒星】。
2. 『暗星』重型狙击枪：极慢拉栓、极高单发伤害、无限穿透，技能【星蚀】【陨星】【星链】【奇点降临】。
3. 『成长棱镜』：击杀怪物获取经验，等级越高召唤越多棱镜神剑。
4. 『深海剑』：挥动释放深海礁石，半空分裂为三枚追踪碎岩。
5. 『深渊法杖』：持续激光，命中叠能量、概率附加减益与回蓝。

二、原初体系
1. 【原初残影】夜晚生成，击败掉落原初碎片。
2. 8 个原初碎片合成【原初核心】；月后用 5 个夜明锭在远古操纵机无限量产。

三、等级与能量
1. 命中积攒星空能量（上限 100），需在设置里拖出 8 个技能键。
2. Leveled 版武器拥有独立经验池与称号。

本模组参考了 tModLoader 的部分模组与启动器上的部分模组代码制作。

适用于柠版泰拉启动器 0.5.1（410）与 Terraria Build 1720。

阮汐月（主创/代码）、茉灵（翻译/修bug）、冷雨（协同开发）。

2.1.1-r.1 能量条和技能输入按手持条件运行。成长经验迁入角色模组数据，真·星空由本地角色的库存触发补经验。

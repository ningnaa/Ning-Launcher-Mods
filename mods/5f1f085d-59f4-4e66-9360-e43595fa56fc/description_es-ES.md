Basado en el Murasama Standalone de Raion Light.

El original exige cuatro teclas en el móvil, lo que es incómodo. Esta versión lo divide en cinco botones táctiles colocables libremente y rehace la detección, los números y lo visual.

## Botones
- **Arte de combate** — mantén para cargar cuando está vacío, toca cuando está lleno para lanzar la hoja; toca otra vez mientras está fuera para impulsarte.
- **Remate** — toca en el aire para Kuuenzan; en el suelo para Impacto.
- **Impacto** (opcional) — botón propio.
- **Getsuga** — botón propio: tercer golpe amplio y luego una onda en medialuna.
- **Ciclón** — mantén en el aire para girar; termina al aterrizar.

## Combate
- **Combo de tres golpes** — el tercero pasa a Corte Amplio: más largo y fino, con hitbox 3× (X) / 2× (Y) de lo visual.
- **Corte Amplio** — sigue siendo daño doble, pero con forma de hoja larga en vez de arco.
- **Getsuga** — 500% del daño del panel; la caja del shader crece con el alcance.
- **Corte Dimensional** — 1024% del daño del panel con grieta a pantalla completa.
- **Impacto / Kuuenzan / Ciclón / Impulso** — 75% / 80% / 60% / 125%.
- Toda hitbox y tajo escala con el atributo Alcance de Ataque.

## Aspectos
23 aspectos de Murasama, receta única (Espada Corta de Cobre + 48 Barras de Hierro/Plomo + 16 Estrellas Fugaces en el Yunque de Hierro). Cada uno tiene paleta, barras de UI y color de nombre propios; las descripciones (daño / crítico / velocidad / empuje) siguen el color de la hoja, y el Arcoíris es letra a letra.

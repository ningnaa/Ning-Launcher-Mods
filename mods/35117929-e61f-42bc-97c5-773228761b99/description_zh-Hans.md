# Universal Map

在多人游戏中，玩家探索过的一切都会出现在每个人的地图上。每分钟，每位玩家都会发送自上次同步以来探索的区域，并接收其他人探索的区域。

## 工作方式

- 只发送新区域，因此首次同步之后的同步数据都很小。
- 共享的区域保持另一位玩家看到的亮度。
- 你自己已经探索过的区域永远不会被覆盖。
- 之后加入的玩家会在加入几秒后收到完整的共享地图。
- 支持专用服务器，也支持由手机主持世界。
- 工作分散在许多帧中完成，因此游戏依然流畅。

## 设置

| 设置 | 作用 |
| --- | --- |
| 间隔 | 两次同步之间的分钟数（1 到 10）。 |
| 通知 | 当你的地图收到新区域时在聊天中显示消息。 |
| 立即共享 | 立即发送你探索过的整张地图。 |

# 伤害类型着色

敌人受到攻击时弹出的伤害数字，以及物品提示中的伤害行，会按照武器的伤害职业着色，效果类似 PvtFudgepants 制作的 tModLoader 模组 Colored Damage Types。

| 职业 | 普通伤害 | 暴击 |
|---|---|---|
| 近战 | [c/AA0000:深红色] | [c/FF0A32:红色] |
| 远程 | [c/96E19B:浅绿色] | [c/1ECD5A:绿色] |
| 魔法 | [c/78BEFF:浅蓝色] | [c/3782FF:蓝色] |
| 投掷 | [c/A06E3C:棕色] | [c/DC8700:橙色] |
| 召唤 | [c/FF73C3:粉色] | [c/FA50FA:洋红色] |
| 哨兵 | [c/9673FF:淡紫色] | [c/7846FF:紫色] |

护甲的防御行也会着色。

> [!TIP]
> 手持其他模组的武器后打开设置，**手持物品职业（Held Item Class）**区域会显示该伤害职业的颜色，可直接修改。

## 设置

- 开启或关闭物品提示和伤害数字着色。
- 隐藏自己和其他玩家的伤害数字。
- **合并伤害（Condense）**：每命中 N 次后显示一次伤害总和，适合攻击速度很快的武器；也可选择在击杀时显示。
- 分别调整每种颜色，或使用**天界柱配色（Pillar Colors）**预设。
- 设置其他模组伤害职业的默认颜色。

## 模组伤害职业

其他模组添加的每个伤害职业都会自动获得配色。模组也可以注册自己的颜色：

```js
const cdt = new Ref();
if (ModLoader.TryGetMod('coloreddamagetypes', cdt)) {
    cdt.value.Call('AddDamageType', ModContent.GetInstance(MyClass), [80, 200, 255], [120, 220, 255], [0, 150, 255]);
}
```

三组颜色依次用于物品提示、普通伤害和暴击。物品提示设为白色时保留游戏自身的颜色。手持该职业武器时，玩家可以在菜单中修改配色；选择**模组默认（Mod Defaults）**可恢复模组注册的颜色。

## 多人游戏

所有玩家都安装模组时，其他玩家的伤害数字也会显示对应职业的颜色，但亮度略低。

支持 12 种语言。

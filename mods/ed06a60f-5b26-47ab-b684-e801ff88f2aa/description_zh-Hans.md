# 连锁挖矿

用镐或钻头挖掉**一块**矿石，与它横向、纵向或斜向相连的同类方块也会一起被挖掉。每个游戏刻处理 10 个方块，按从近到远的顺序进行。

默认支持游戏中的全部**矿石**、**宝石**、**泥沙**、**雪泥**、**沙漠化石**和**黑曜石**。

## 添加自定义方块

手持对应方块的放置物品，然后在聊天栏输入：

| 命令 | 功能 |
|---|---|
| `/vein add` | 将手持方块加入列表。 |
| `/vein remove` | 从列表中移除手持方块。 |
| `/vein list` | 查看个人列表。 |
| `/vein clear` | 清空个人列表。 |
| `/vein on` / `/vein off` | 开启或关闭连锁挖矿。 |

该列表对所有世界和角色生效。

## 配置

可设置 **Vein Miner** 开关、**矿石（Ores）**、**默认列表（Default List）**、**添加的方块（Added Blocks）**及清空按钮，以及每条矿脉的**最大方块数（Max Blocks）**。

支持英语、葡萄牙语、西班牙语、法语、德语、意大利语、波兰语、俄语、简体中文、繁体中文、日语和韩语。

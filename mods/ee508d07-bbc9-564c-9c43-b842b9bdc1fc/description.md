# 合成表（C#）

搜索物品与配方，查询制作路径、制作站、掉落和收藏。搜索框支持手机键盘。

适用于柠版泰拉启动器 0.5.1（410）与 Terraria Build 1720。请使用包含相应移动兼容修订的启动器构建。与同功能 JS 版二选一启用。

jopojelly（原模组作者）、柠版泰拉启动器（移动版汉化与维护）。

## 本版修复

合成表失去绘制权限时会关闭面板和模组筛选下拉框，之后可从背包重新打开。 弹窗关闭后恢复游戏界面需搭配柠版泰拉启动器 0.5.2（411）或更新版本。适用 Terraria Build 1720。

修复触屏从背包拖入配方、制作和怪物图鉴查询槽。查询不会消耗原物品，划过槽位后在其他位置松手不会提交查询。

适用于柠版泰拉启动器 0.5.4.4（416）与 Terraria Build 1720。

制作人员　jopojelly（原模组作者）、柠版泰拉启动器（移动版汉化与维护）。

## 真实游戏回归

Android 9模拟器、启动器0.4.15、运行库301720；独立复制人物和世界。9组场景79项检查通过，最终材质包无贴图尺寸警告，相关场景无模组异常或原生崩溃。

- 魔法存储：真实连接方块与实体、存取、收藏保护、制作工作台、安装制作站、升级、远程访问；调用游戏保存并完整重启，数量、容量、制作站和远程绑定均保持。
- 更好的体验：原生弹药选择与消耗、开关恢复、便携工作台、挖矿速度、放置距离、一键关闭。发现关闭制作站后原版邻接缓存残留，在配置OnApply中刷新AdjTiles及配方；修订1.0.2-ningzh.1.fix.1复测通过。
- 自动钓鱼：真实水池手动抛竿、自然鱼获、自动收线入包及锁定目标重抛；原生药剂自然到期续喝三种药水。旧版使用原生桥接函数不存在的.call属性而失败，改为有对象绑定的原生调用；修订0.1.0-test1.ningzh.1.fix.1复测通过。
- 炼金术师：8个NPC实际生成与中文对话，移动端商店实际购买与扣币，模组药剂实际消耗、Buff和抗击退效果。购买验证等待商店完成初始化，未把同帧触发造成的测试假失败作为模组缺陷。
- 4个材质包：原版基线、启用后的玻璃/火环/背景/方块/背包画面、关闭恢复、重新启用；铸造与炼金的“穹顶”名称生效且关闭后恢复“天顶剑”。

测试结束恢复原设置与模组配置，7个人物文件、11个世界文件、684个既有模组文件保持原哈希。临时人物、世界与测试模组移除。源PNG、UID、原作者、已有许可未改。两源先验证附件，再更新目录。

## 限制

通过的是代表性单人玩法和资源生命周期回归，不是所有物品、全部Boss动画、所有配置组合或双设备联机的穷尽验证。魔法存储现有界面只支持单人；自动钓鱼保留测试版标识。我的世界材质包数量多，实测进程内存明显高于原版，应考虑设备内存容量。未更新启动器版本或应用更新提醒。

# 掉落物光柱

按照物品稀有度，为掉落物添加《无主之地》风格的**光柱**和**光晕**，类似 ChemAtDark 制作的 tModLoader 模组 Loot Beams。

- 使用稀有度对应的颜色，支持模组稀有度；专家物品为彩虹色，大师物品为火焰橙色，任务物品为金色。
- 物品落地时闪光，光柱会脉动，拾取后逐渐淡出。
- 金币、生命心和魔力星会像原作一样显示各自颜色的小光柱。
- 光柱有普通、箭头和动态箭头样式；光晕有柔和与像素样式。
- 可选择让物品照亮周围。

## 设置

可设置最低稀有度、最低价值、始终高亮任务/专家/大师物品、光柱与光晕的尺寸和透明度、闪光尺寸、更明亮的叠加光柱、脉动、照明及默认筛选列表。

## `/beams` 命令（使用时手持物品）

| 命令 | 功能 |
|---|---|
| `/beams always` | 让当前物品始终显示光柱。 |
| `/beams never` | 让当前物品从不显示光柱。 |
| `/beams mini` | 切换小光柱。 |
| `/beams color #RRGGBB` | 自定义光柱颜色。 |
| `/beams reset` | 将当前物品从个人列表中移除。 |
| `/beams list` / `/beams clear` | 查看或清空个人列表。 |
| `/beams on` / `/beams off` | 开启或关闭光柱。 |

支持 12 种语言。

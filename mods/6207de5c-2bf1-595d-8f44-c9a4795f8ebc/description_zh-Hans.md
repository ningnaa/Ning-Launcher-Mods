# 堆叠上限增强（Max Stack Plus Extra）

原作者：**NuovaPrime**。tModLoader 1.4 移植：**RighteousRyan**。Bunny Loader 移植者：**柠娜**。本包基于 Steam 已订阅的 1.4.0.3，为当前 Bunny Loader 运行库重新适配。

## 五类配置

| 类别 | 默认上限 |
|---|---:|
| 普通物品 | 9999 |
| 方块 | 9999 |
| 武器 | 1 |
| 装备 | 1 |
| 特殊物品 | 1 |

所有选项可设为 **1–32767**，硬币保持游戏原版规则。移动版箱子使用较小的整数存储，因此不提供原 PC 模组的超大整数或 0 上限。

在**游戏主菜单 → 设置 → 模组配置**调整。保存后完全退出并重启游戏生效，世界内不显示这组设置。联机配置采用房主发送的设置；目前已完成收发和范围校验的模拟回归，尚未完成双设备联机实测。

## 兼容与存档

- 保留普通物品、方块、武器、装备、特殊物品的区分；弹药、投掷物、桶等不会仅因为有伤害或防御数值就被误归类。泥土沿用原模组规则，归普通物品。
- 保留原作者提示：将武器或装备设为大于 1，可能影响其他模组的词缀与独立物品数据，默认保持 1。
- 降低配置时，本包不主动删除已有数量；在安全范围内的旧大堆叠可以暂时保留更高上限，整理或重新生成物品后再采用新上限。
- **禁用或卸载前，请先把物品拆分至原版允许的数量并备份存档。** 本包被禁用后无法保护超出原版上限的堆叠，游戏可能截断超出部分。
- 已测试原版物品和标准 JS 模组物品初始化；未验证所有第三方模组或 C# 内容模组。

不修改游戏存档格式，不提升启动器版本。原包没有附独立许可证，本包不补写或推定其他许可。

# 哥布林砍价

现在，你可以用任意武器攻击**哥布林工匠**，降低他的重铸价格。

- 初始重铸费用为物品价值的 **50%**。
- 每次命中（近战或弹幕）降低 **5%**，最低降至 **5%**。
- **15 分钟**内没有再被击中，价格会恢复初始值。
- 哥布林工匠死亡时，价格重置。
- 每次命中都会在他头顶显示新的价格。

当前价格会随世界保存。

## 配置

支持设置**不死**（玩家的攻击不会杀死他）、**显示价格**、**初始价格**、**每次命中折扣**、**最低价格**和**重置时间（分钟）**。

本模组移植自 tModLoader 模组 *Abuse Goblin*。

支持英语、葡萄牙语、西班牙语、法语、德语、意大利语、波兰语、俄语、简体中文、繁体中文、日语和韩语。

# 更好的体验

提供储存管理器、钓鱼机、药水袋、旗帜盒和多种建造工具。部分功能需在模组配置中开启。需要配套的 SilkyUI。

适用于柠版泰拉启动器 0.5.1（410）与 Terraria Build 1720。需要 SilkyUI。

局长, Cyril, 夜谷紫幽, delete, Kaelis, Lacewing, Lastprismer, 合作一号, Reits, 中学生, 错数螺线, Zavarski, Pengolin（原模组作者）、柠版泰拉启动器（移动版汉化与维护）。

## 本版修复

修复 Radial Hotbars 图层临时缺失时的界面排序报错。图层恢复后会重新参与排序。 弹窗关闭后恢复游戏界面需搭配柠版泰拉启动器 0.5.2（411）或更新版本。适用 Terraria Build 1720。 需要 SilkyUI。

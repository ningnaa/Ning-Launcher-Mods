# 我的世界材质包

用像素方块风格重绘方块、墙、背景、物品和界面等贴图。

移植者：m。原作者：Melstar、The Lamb。源包未附独立许可证声明，保留原有署名与资料。

安装并启用后重启游戏；关闭后重启可恢复原版。多个材质包覆盖同一图片时，以加载优先级为准。

原作：Melstar's Minecraft Texturepack。本包以提供的4349张图片为范围；原作其他版本的声音、音乐和语言资源不包含在本包内。图片数量较多，运行内存占用较高。

原作：https://steamcommunity.com/sharedfiles/filedetails/?id=2439772075

手机版兼容版：97张与手机版布局不一致的旧版或电脑版贴图保留原版显示，原图保存在 source/incompatible，不会覆盖游戏贴图。其余4252张图片参与替换。

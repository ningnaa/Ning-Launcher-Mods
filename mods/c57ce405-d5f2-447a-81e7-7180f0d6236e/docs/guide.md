# 星星家族 · 玩法说明

> 潜龙出渊，厚积薄发。

## 潜龙之星

一件会随在线时间慢慢变强的饰品。佩戴后头顶跟着一颗青蓝色小悬浮星；在线越久，防御、伤害、速度、免伤和仆从/哨兵位越高。

新世界第一次挥动工具时，潜龙之星会自天而降砸中你（扣一颗心），落地后变成可拾取的掉落物；也可在工作台用坠落之星 ×5 + 生命水晶 ×1 合成。

## 七种能力

拿潜龙之星去和 Boss 遗物合成，即可永久解锁一种能力，顺序随意：

| 遗物 | 能力 |
| --- | --- |
| 史莱姆王遗物 | 史莱姆之力 |
| 克苏鲁之眼遗物 | 克苏鲁之力 |
| 蜂王遗物 | 蜂王之力 |
| 世界吞噬者遗物 | 蠕虫之力 |
| 克苏鲁之脑遗物 | 克脑之力 |
| 骷髅王遗物 | 骷髅王之力（白天减伤 5%，夜晚伤害 +5%，+20 生命、+20 法力） |
| 肉山遗物 | 肉山之力（全图掉落物吸附到身边） |

## 星族武器

五把武器都需要先佩戴潜龙之星才能在合成列表里看到：

| 武器 | 材料 |
| --- | --- |
| 剑星（近战） | 坠落之星 ×3 + 木头 ×50 |
| 彗尾长弓（远程） | 坠落之星 ×3 + 木头 ×50 |
| 星核法杖（魔法） | 坠落之星 ×3 + 木头 ×50 |
| 坠星召唤杖（召唤） | 坠落之星 ×3 + 木头 ×50 |
| 双子星（远程） | 火枪 ×1 + 坠落之星 ×5 + 铜锭 ×10 |

双子星消耗普通火枪子弹。平时是速射机枪，单发星弹不带击退；怪物贴到枪口附近时自动切成散弹，扇形齐射并击退，攻速减半；怪退开后自动切回机枪。机枪模式前置加特林枪管伸出，散弹模式枪管收回，切换时有逐帧伸缩过渡。

## 重铸词缀

武器可由哥布林工匠重铸出本族词缀（吸血、坚盾、追迹、迅疾、闪避、强心、星芒、光芒万丈）。

## 设置

模组设置里可开关头顶悬浮星的显示，以及潜龙之星是否说话；七种 Boss 之力（史莱姆、克眼、蜂王、蠕虫、克脑、骷髅王、肉山）也各自有独立开关，关掉后该能力即使已解锁也暂不生效，饰品基础成长属性不受影响。

## 星星家族指南

在游戏控制键绑定界面把「星星家族指南」动作键绑到一个按键/触屏按钮，按下即可打开自建图鉴面板。首页以自绘卡片列出武器、饰品、材料、其他、更新日志五类；点进大类后，武器再分近战、远程、魔法、召唤子类，其余类直接列出条目；点条目进入详情页，查看属性数值、合成材料图标与数量、制作站和功能说明，长内容可上下滚动，可逐级返回。更新日志按版本列出每次改动，新版本往日志数组头部追加。

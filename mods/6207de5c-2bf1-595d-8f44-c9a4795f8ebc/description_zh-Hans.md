# 堆叠上限增强

分别调整普通物品、方块、武器、装备和特殊物品的堆叠上限，减少整理背包的次数。硬币保持原版堆叠规则。

| 类别 | 默认上限 |
|---|---:|
| 普通物品 | 9999 |
| 方块 | 9999 |
| 武器 | 1 |
| 装备 | 1 |
| 特殊物品 | 1 |

所有选项可设为 **1–32767**。泥土沿用原模组的分类，使用“普通物品”设置。

## 使用方法

在**游戏主菜单 → 设置 → 模组配置**中调整，点击应用后完全退出并重启游戏。世界内不显示这组设置。

## 使用注意

- 武器和装备默认上限为 1。提高上限可能与其他模组的词缀或独立物品数据冲突。
- 降低上限不会立即删除已有数量，旧的大堆叠可能暂时保留较高上限。
- **禁用或卸载前，先将物品拆分到原版允许的数量并备份存档。** 否则游戏可能截断超出的数量。
- 联机使用房主设置，但联机兼容性尚未充分验证；部分第三方内容模组可能存在兼容问题。

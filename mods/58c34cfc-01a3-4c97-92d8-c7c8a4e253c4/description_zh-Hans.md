# 星之铃 StarBell

> “一声笛响，群星坠落。她从星辰的倒影中走来————带走了寂灭，孕育繁星的火种.........”

这支笛子并非凡物，它诞生于繁星之花，表面刻满了月相与繁星的脉络。当吹奏者轻轻吹响它时，笛声清澈悠远，仿佛能唤醒夜空最深处的星光。

或许它每一首的旋律都听过，然而，无论它承载了多少星光，每一个拿起它的人，都终究会在旋律中，留下一段只刻在星轨上的无声独奏。既然命运将它交予你，希望你能用它奏出独属于你的旋律....

## 获取方式

它不是合成品，工作台、恶魔祭坛都做不出来，只能靠一场“坠星”：

- **时间**：夜晚（游戏进入夜晚后，白天使用无效）。
- **动作**：手持**坠落之星**（Fallen Star，天上掉下来的那种）点“使用”。
- **判定**：每次使用有 **60%** 概率触发坠星，从你头顶落下；没中就直接再点一颗，每次独立判定，几颗之内基本必出。
- **结果**：坠星落地后变成**繁星花笛**，走过去捡起即可。
- **限制**：每个世界只能这样获得一次，拿到后这个世界不会再触发；联机时由服务端判定并同步给所有人。

## 击败 Boss 的升级顺序

繁星少女的强度不看召唤杖、只看你**在这个存档里已经击败过哪些 Boss**：取已满足条件中顺位最高的一档，伤害与射程逐级提升。

表中的伤害是笛子面板伤害为 8 时的基础值，实际伤害会随召唤伤害加成等比放大。

- **未击败任何 Boss**：8 —— 只会贴身跟随与扑击
- **史莱姆王**：10 —— 解锁拉弓，射出「星之箭」
- **克苏鲁之眼**：12 —— 扑击可同时命中 10 个目标
- **世界吞噬者 / 克苏鲁之脑**（任一）：14 —— 解锁「星辰散射」
- **蜂王**：16
- **骷髅王**：18
- **血肉之墙**：24 —— 进入困难模式阶段
- **史莱姆皇后**：28
- **毁灭者**：32
- **双子魔眼**：36
- **机械骷髅王**：40
- **世纪之花**：46
- **石巨人**：50
- **猪龙鱼公爵**：55
- **光之女皇**：66
- **拜月教邪教徒**：72
- **月亮领主**：5213 —— 终曲形态

进度按上表从上往下打即可；击败 Boss 时她还会说一句对应的话，进阶时也有提示。

## 内容

- 物品 **繁星花笛**（召唤武器，消耗召唤栏召唤繁星少女）
- 增益 **繁星少女**
- 随从 **繁星少女**：空闲跟随 / 索敌追击 / 扑击 / 拉弓蓄力 / 射星 / 星辰散射等完整行为
- 弹幕 **星之箭**、**坠星**
- 首次拾取时的引导提示（GlobalItem 触发）

## 移植说明

本包由 PC 端 tModLoader 模组（`StarBell.tmod`，v1.16）移植而来：

1. 解包 `.tmod`，取出 `StarBell.dll` 与全部内容资源；
2. 反编译 IL 得到 C# 源码，按 Bunny Loader 的 tModLoader 兼容层逐处改写（`Item`/`NPC`/`Projectile` 在 Bunny Loader 中是原生结构体代理、`Color` 位于 `Graphics` 命名空间、`SoundStyle` 需要用 `with` 表达式、`WorldItem` 替代世界物品的 `Item` 等）；
3. 用启动器自带的 `BunnyLoader.dll` + 同一套 Roslyn 引用重新编译，保证与手机端 API 完全一致；
4. `.rawimg` 纹理（BGRA）转回标准 PNG，放到与 PC 版相同的 `Content/` 目录；
5. 按 `blVersion 3` 规范重新打包为 `.bl`。

## 已知差异

- 掉落在地上的笛子周围的星光尘埃（`ModItem.PostUpdate`）无法还原：Bunny Loader 的 `Item` 结构体没有世界坐标与 `timeSinceItemSpawned`。
- 联机同步（`ModPacket`）与世界存档标记沿用 Bunny Loader 的兼容实现，单人模式下不受影响。

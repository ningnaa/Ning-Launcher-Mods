# Nouveautés

## 1.3.8.5

- Gnorp utilise maintenant le bon sprite quand il est assis (sur mobile,
  l'image était décalée d'une case).
- Traduit dans toutes les langues de Terraria : allemand, français, espagnol,
  italien, russe, polonais et chinois.

## 1.3.8.4

- L'aperçu (image, contour de poussière et bouton Point d'ancrage) ne reste
  plus sur un emplacement vide après avoir utilisé le dernier globe.

## 1.3.8.3

- Nouveau point d'ancrage par défaut : en bas au centre. Le bâtiment s'élève
  depuis le bloc touché, et tu vois jusqu'où il va. Les quatre coins sont
  toujours là.
- Le bouton tactile s'appelle maintenant Point d'ancrage.

## 1.3.8.2

- L'image d'aperçu est maintenant dessinée avec le monde (juste après les
  PNJ), avec le zoom du jeu : elle était décalée et suivait le zoom de l'écran.

## 1.3.8.1

- Portage de Gnorp's Builder 1.3.8.1 sur Bunny Loader.
- Les 116 bâtiments ont été convertis depuis les fichiers de StructureHelper
  et sont construits par le mod lui-même (StructureHelper n'est pas
  nécessaire).
- Mobile : le coin se change avec le bouton tactile Point d'ancrage (clic droit
  sur PC) ou dans les réglages ; les globes ne se réutilisent pas tout seuls ;
  les détails de la description sont toujours affichés.
- Multijoueur : les joueurs demandent au serveur, qui vérifie la demande,
  construit et synchronise la zone.

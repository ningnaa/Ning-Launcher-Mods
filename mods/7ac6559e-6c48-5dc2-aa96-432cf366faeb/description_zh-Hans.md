# 更好的体验

提供储存管理器、钓鱼机、药水袋、旗帜盒和多种建造工具。部分功能需在模组配置中开启。需要配套的 SilkyUI。

## 更好的体验 1.8.2-r.2（2026-11-20）

- 修复解锁自动存钱后，人物存档在退出、重进和再次保存时可能损坏的问题。
- 自动存钱的三个档位和过滤设置继续可用，档位会随人物的模组数据保存。
- 已损坏的人物可用修复后的存档副本或备份恢复。
- 适用于柠版泰拉启动器 0.5.3（412）及 Terraria Build 1720。需要 SilkyUI。

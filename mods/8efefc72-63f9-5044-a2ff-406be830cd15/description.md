# 魔法存储

用存储核心和存储单元集中管理物品，通过制作界面使用库存合成，并可通过微光界面转化物品。

- 修复联机物品提取、带自定义数据的大库存快照及存储核心升级和还原。修复私有存储的操作权限与创造单元状态同步。
- 修复移动房主合成和微光操作后库存不变的问题，以及制作站装入或取回不同步、取回重复入包的问题。
- 修复制作页容量显示、数量与稀有度升降序、微光结果区高度及普通物品预览报错。

适用于柠版泰拉启动器 0.5.4.3（415）及 Terraria Build 1720，需要 absoluteAquarian Utilities。联机请使用相同版本。递归合成烈焰箭可能卡住游戏，此问题仍在排查。

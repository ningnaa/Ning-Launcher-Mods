# 炼金术师 NPC 轻量版

添加炼金师、药剂师、珠宝师、年轻药剂师、操作员、建筑师、音乐家和工匠，提供药水、材料、组合药剂及便利道具。

击败克苏鲁之眼后，炼金师、药剂师和珠宝师可入住；困难模式且炼金师、药剂师在场时，年轻药剂师可入住。操作员需要击败世界吞噬怪或克苏鲁之脑，建筑师需要世界中至少有3名NPC，音乐家需要击败骷髅王。各项开关和价格可在模组配置中调整。

跨模组商店取决于对应内容是否可用；原电脑版的兼容列表不代表本移植版已经逐项验证。联机兼容性尚未充分验证。

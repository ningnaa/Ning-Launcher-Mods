本模组基于 Raion Light 的 Murasama Standalone 制作。

## 按键
- **战技键**：未满能量时按住充能，满能量轻点投刀；飞刀在场时再次轻点触发突进斩
- **终结键**：空中轻点释放空刃斩；站在地面轻点释放震地猛击
- **震地键**：独立触发震地猛击
- **月牙键**：独立触发月牙天冲——先挥出第三段横扫，再甩出一道月牙刃气
- **旋风键**：空中按住持续旋转，落地即止

## 战斗
- **横扫**：伤害倍率为双倍
- **月牙天冲**：500% 面板伤害
- **次元斩绝**：1024% 面板伤害
- **震地猛击 / 空刃斩 / 旋风斩 / 突进斩**：75% / 80% / 60% / 125%。
- 所有技能判定与刀光同步受「攻击范围」属性影响。

## 涂装
23 款村正，统一配方（铜短剑 + 铁/铅锭 ×48 + 坠落之星 ×16，铁砧处合成）。每款都有独立的配色、UI 条、物品名颜色，物品提示（伤害 / 暴击 / 速度 / 击退）也跟随刀身主色；虹彩款为逐字流动彩虹

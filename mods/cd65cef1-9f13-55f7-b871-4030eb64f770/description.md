# 商店翻页

原作 Shop Expander 1.8.1，原作者与维护者 DRKV、Exterminator；Bunny Loader 移植者柠娜。原 MIT 许可和版权信息随包保留。

在原生商店中浏览超出一页的商品，保留价格、特殊货币和物品附加数据。每页最多显示 40 件商品，购买按钮左侧的小型“上一页”“下一页”用于切换；长按可以跳到首尾页。到达边界时，相应按钮变灰。

只有商店打开、商品超过一页时才显示分页按钮。一页能放下的商品、附加商品及回购物品合并显示，避免为了少量物品额外翻页；大型商店保留按优先级排列的附加页和回购页。回购缓存保留原作最近 38 个槽位的覆盖规则，关闭并重新打开商店会重建。

模组设置中的禁用列表每行填写一个 NPC 标识符，例如 `Merchant`；模组 NPC 使用 `模组ID/类名`。下次打开该 NPC 的商店时使用原版布局。

需要支持完整商品列表和字符串列表配置的 Bunny Loader 兼容版本。

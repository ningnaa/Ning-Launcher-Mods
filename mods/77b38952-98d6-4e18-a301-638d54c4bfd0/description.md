Teleporta todos os NPCs de cidade para suas casas.

- Use `/npchome` para mandar todos os moradores de volta para casa.
- Quando a casa de um NPC muda, ele é levado para a nova na hora.

### 1.0.0-r.2 更新

只在实际运行城镇 NPC 行为时处理住房变更。使用回家指令时才遍历所有已入住的城镇 NPC。

此版本适用于柠版泰拉启动器 0.5.4.3（415）和 Terraria Build 1720。

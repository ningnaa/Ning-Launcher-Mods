# 金字塔丛林神庙

将丛林神庙改造成由丛林蜥蜴砖构成的金字塔。设计参考原作者提供的示意：上窄下宽，拱顶房间分布在不同楼层，层与层之间由较厚的砖墙隔开。

- 包含底层在内，小世界为五层、中世界六层、大世界七层；地下深度不足时会减少层数。
- 主要楼层间隔 64 至 70 格，部分房间带有高低差。
- 八种房间：柱廊、尖刺坑、阶梯式大厅、带壁龛的宝藏室、高大厅、低矮走廊、陷阱通道和带平台的遗迹。各房间宽度、高度和屋顶形状不同。
- 每层通过水平走廊和阶梯式下降通道连接，下降方向逐层交替。
- 底部中央大厅宽 170 至 210 格、高 58 至 68 格，带有悬挂柱、阳台和置于高台上的祭坛。
- 入口放置锁定的丛林蜥蜴门，并直接使用正确样式构建。
- 每层都有丛林蜥蜴箱，使用游戏的掉落生成流程填充，包括丛林蜥蜴电池。计划箱子数量为房间数的 35%，向上取整。
- 带有规划好的陷阱电路：用红、蓝或绿电线，将丛林蜥蜴压力板连接到超级飞镖机关、烈焰机关、尖球机关和长矛机关；另有铺设尖刺的坑。
- 在保留金字塔轮廓的前提下，将外围多余边距缩减 38%；底部厚度从 12 格减为 7 格。
- 游戏后续的 `templePart2` 阶段仍可添加装饰、家具和危险机关。

## 使用方法

1. 在 Bunny Loader 的**资源包**页面导入并启用 **Templo Pirâmide**。
2. 打开或重启游戏。
3. **创建新世界**。模组修改的是神庙生成流程，已有世界保留原来的神庙。

神庙位置由泰拉瑞亚在丛林中选择。模组会调整布局，使其处于世界边界内，并位于地狱上方。

不会调用原版 `makeTemple` 生成器。发生错误时会记录日志，并将异常限制在模组内部，避免在金字塔上再生成另一个神庙。

请只使用一种生成器版本：模组包或编辑器脚本二选一。其他替换 `makeTemple` 的模组也会争用同一生成流程。

# Flat Seed

一个平到可以放心狂奔的世界，再也不怕绊倒或掉进坑里！地表会变得完全平坦，其他一切照常生成：洞穴、生物群系、矿石、地牢、神庙、浮空岛以及地狱。

## 使用方法

这是一个**秘密种子**。创建新世界时，在种子栏中输入以下任意代码：

| 语言 | 代码 |
|---|---|
| English | `flat`, `flat world`, `superflat` |
| Português | `plano`, `mundo plano`, `superplano` |
| Español | `plano`, `mundo plano` |
| Français | `plat`, `monde plat` |
| Deutsch | `flach`, `flache Welt` |
| Italiano | `piatto`, `mondo piatto` |
| Polski | `płaski`, `płaski świat` |
| Русский | `плоский`, `плоский мир` |
| 中文 | `平坦`, `平坦世界`, `平面世界` |
| 日本語 | `平ら`, `平らな世界` |
| 한국어 | `평평`, `평평한 세계` |
| Tiếng Việt | `phẳng`, `thế giới phẳng` |
| ไทย | `แบน`, `โลกแบน` |

它也会出现在游戏的秘密种子列表中，可以与其他秘密种子组合使用。只有用它创建的新世界才是平坦的，你的其他世界不受影响。

## 世界生成

生成过程中会出现新的步骤**正在铲平世界...**（游戏内文字以游戏语言显示）：它会把地表整平，平滑通往海滩的斜坡，并在表面保留一层土。不会生成山丘、隧道和地表湖泊。浮空岛会完整保留，包括岛上的沙子。

与秘密种子 **Mole People**（没有地表）一起使用时，世界不会被铲平。

## 选项

在主菜单中：**设置 > 模组配置 > Flat Seed**。

| 选项 | 作用 |
|---|---|
| 地表高度 | 平地的位置，以世界高度的百分比表示（默认 20%）。 |
| 填平裂缝 | 同时填平地表上出现的洞和裂缝。 |
| 海滩斜坡 | 从平地到海洋的平缓斜坡。 |

## 说明

与内容类模组一起使用时，世界生成期间画面可能会短暂看起来卡住：世界仍在生成，请耐心等待。

Основано на Murasama Standalone от Raion Light.

## Кнопки
- **Боевой приём** — удерживайте для заряда, коснитесь на полном заряде, чтобы метнуть клинок; коснитесь снова, чтобы совершить рывок.
- **Добивание** — в воздухе: Кууэндзан; на земле: Землетрясение.
- **Землетрясение** — отдельная кнопка.
- **Гецуга** — отдельная кнопка: третий широкий удар, затем волна-полумесяц.
- **Вихрь** — удерживайте в воздухе; заканчивается при приземлении.

## Бой
- **Широкий разрез** — двойной урон.
- **Гецуга** — 500% урона; рамка шейдера растёт вместе с радиусом.
- **Пространственный разрез** — 1024% урона с полноэкранным разломом.
- **Землетрясение / Кууэндзан / Вихрь / Рывок** — 75% / 80% / 60% / 125%.
- Все хитбоксы и взмахи масштабируются от характеристики «Радиус атаки».

## Облики
23 облика Мурасамы с одним рецептом (Медный короткий меч + 48 слитков железа/свинца + 16 падающих звёзд на железной наковальне). У каждого своя палитра, полосы UI и цвет названия; подсказки предмета (урон / крит / скорость / отбрасывание) окрашиваются в цвет клинка, а Радуга — по буквам.

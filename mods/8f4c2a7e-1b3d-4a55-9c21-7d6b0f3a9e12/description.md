优化设置界面，修复一处可能导致物品和能量消失的问题。可学习物品、回购、合成补料和管理仓库。更新前请备份角色存档。

## 作者说明

# 转化桌- 实用物资管理工具
这是一个让你彻底告别翻箱倒柜的模组。它把存东西、找东西、做东西、洗装备全部整合在了一个界面里。

# 怎么拿：

开局就送： 只要是新建的人物，包里自动自带一个。

手工作坊： 老角色可以用 15个任何铁锭 + 10个任意邪恶锭 + 5个黄玉和5个红玉 在工作台直接合成。

# 好用的功能：

左边那个“转化槽”： 核心功能位。把东西放进去就能“学会”它，以后就能随时回购。放材料进去，中间就会显示它能做的所有合成表。

点图标找东西： 界面顶上一排大图标，分好了武器、衣服、材料等分类，点一下直接跳转。

缺材料直接买（核心）： 进去合成界面，右边会清清楚楚列出合成材料清单。要是发现包里缺了几样，根本不用跑回箱子拿，缺啥直接花能量当场补齐，强行合成！

买东西快： 按的时间越久速度越快

多种排序： 找东西嫌乱？点一下排序按钮，可以按价格、物品ID或者名字字母来排队。

无限大仓库： 切换到仓库模式，东西随便往里扔。支持无限堆叠

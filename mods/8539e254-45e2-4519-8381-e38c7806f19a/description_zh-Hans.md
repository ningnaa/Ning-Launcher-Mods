# 共享背包

多人游戏中以**房主的数据为准**。所有玩家共用房主的背包：客户端拾取、丢弃、制作或在栏位间移动的物品，会先同步到房主，再同步给所有人。

## 共享内容

- **背包**的所有栏位，包括钱币和弹药栏。
- **盔甲、饰品和时装**。
- **宠物和照明宠物**栏位。
- **染料**（`dye` 和 `miscDyes`）。
- **生命值与魔力值**：共用同一数值池。任何玩家受伤、治疗、消耗魔力或回复，都会改变这个共享数值。

## 加入房主的世界

- 你原来携带的物品会放入房主背包的空栏位。**每个角色只进行一次**，并在存档中记录。
- 随后，你的背包会切换为共享背包。
- 放不下的物品会掉落，聊天栏会提示未能放入的数量。

## 已知限制

- **模组物品的额外数据**不会传输，也就是模组写入物品内部的自定义数据。同步时仅保留物品类型、堆叠数量和修饰语；原版物品则会完整同步。
- **光标上的物品**，即用鼠标或手指拿起、尚未放入栏位的物品，要放回栏位后才会同步。
- **保险箱、猪猪存钱罐和箱子**不参与共享，仍按游戏原有方式运行。
- 两位玩家在**完全相同的时刻修改同一个栏位**时，以房主最后处理的操作为准，所有人最终获得该结果。
- **所有玩家都需要安装本模组，并保持内容模组一致**，这是 Bunny Loader 的要求。

## 测试方法

1. 在房主和客户端都安装模组，可放入 `bunny_packs/` 或导入 ZIP。
2. 使用测试角色。客户端加入时，其物品会转交给房主。
3. 房主以多人模式打开世界，客户端加入。
4. 双方分别拾取、丢弃、移动物品，并测试受伤和消耗魔力，确认背包与生命值在所有玩家处一致。

日志中的 `bl.log` 输出会写入游戏日志文件，并以 `Shared inventory: ...` 开头。

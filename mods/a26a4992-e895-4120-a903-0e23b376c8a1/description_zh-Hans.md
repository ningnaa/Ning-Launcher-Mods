# 溢出生命值

将 JADen 制作的 tModLoader 模组 **Overhealth** 移植到 Bunny Loader。

当生命值接近满值时接受治疗，超出生命上限的部分会转化为临时的**溢出生命值**：

- 相当于生命上限的临时扩展：**受到伤害时优先扣除溢出生命值**。
- 它会缓慢衰减，数量越多，衰减越快；公式与原作一致，由固定部分与随数量增长的部分组成。
- 自然生命再生不会产生溢出生命值。
- HUD 会用金色心形、进度条和 `+N` 计数器显示它。

**模组配置选项**：启用开关、最大溢出生命值（生命上限的百分比）、固定/递增衰减及倍率、HUD 开关、位置、尺寸、不透明度和调试日志。

## 与电脑版的差异

- 原作通过修改 IL 解除游戏的生命值上限，Bunny Loader 无法采用这种方式。本版本将溢出生命值单独记录在普通生命值旁，因此游戏自身的血条不会改变，额外数值由金色 HUD 显示。
- 通过游戏的治疗效果检测回复量，因此药水、生命心、吸血等都会计入。中毒、燃烧等不经过游戏普通受伤调用的伤害不会被溢出生命值吸收。
- 仅作用于本地玩家，多人游戏中不会显示其他玩家的溢出生命值条。

Raion Light의 Murasama Standalone을 기반으로 합니다.

원본은 폰에서 키가 4개 필요해 조작이 번거롭습니다. 본 버전은 자유롭게 배치 가능한 5개의 터치 버튼으로 나누고 판정·수치·비주얼을 크게 재작업했습니다.

## 버튼
- **전투 기술** — 충전이 부족하면 길게 눌러 충전, 가득 차면 탭하여 투척. 비도가 있을 때 다시 탭하면 돌진.
- **마무리** — 공중에서 탭하면 공인참, 지상에서 탭하면 진지강타.
- **진지강타** (선택) — 전용 버튼.
- **월아천충** — 전용 버튼. 3단 휩쓸기 후 월아 파동을 날립니다.
- **회오리斩** — 공중에서 길게 누르면 회전, 착지하면 종료.

## 전투
- **3단 콤보** — 3단계가 휩쓸기로 변경: 더 길고 얇은 칼날, 판정은 시각의 3배(X) / 2배(Y).
- **휩쓸기** — 배율은 기존 2배, 형태는 원형 참격에서 긴 칼날로.
- **월아천충** — 패널 피해 500%, 공격 범위에 따라 셰이더 박스 확대.
- **차원참절** — 패널 피해 1024%, 전체 화면 균열.
- **진지강타 / 공인참 / 회오리斩 / 돌진** — 75% / 80% / 60% / 125%.
- 모든 판정과 칼날이 공격 범위에 따라 확대됩니다.

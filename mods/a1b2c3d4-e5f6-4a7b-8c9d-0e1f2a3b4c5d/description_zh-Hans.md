# 咒术回战·先行版

加入五条悟 Boss 和咒力系统，可解锁咒力附魔、简易领域和领域展延。

在石巨人后使用「狱门疆」召唤五条悟。随着世界进度可解锁玩家咒力能力，移动端提供咒力附魔、简易领域和领域展延的触屏按钮。

## 咒术回战·先行版 1.0.44-e（作者版本 1.0.44e，2026-11-21）

- 五条悟的「无量空处」改为由 80%、60%、50%、30%、10% 五档生命值触发。战斗中每档最多展开一次，仍受术式熔断和当前行动状态限制。
- 适用于支持 C# 模组的柠版泰拉启动器和 Terraria 1.4.5.8.6（Build 1720），无需额外前置。

# 成长型武器

作者：阮汐月。当前包含一件成长型召唤武器：成长型泰拉棱镜。保留原包MIT许可声明。

## 制作与使用

在工作台使用10个铁锭或铅锭、3颗坠落之星、5个金锭或铂金锭制作。

手持武器后自动补充飞剑，初始基础伤害12、飞剑上限1。切换到其他武器时，已经召唤的飞剑继续存在；将本武器移出背包或角色死亡后，飞剑消失。重新手持可再次召唤。

## 成长

读取当前世界的Boss进度，各阶段奖励只计一次，重复击败同一个Boss不会重复叠加。伤害倍率相乘，最终向上取整；飞剑数量奖励相加。

| 达成条件 | 伤害倍率 | 飞剑上限增加 |
|---|---|---|
| 克苏鲁之眼 | ×1.20 | +1 |
| 骷髅王 | ×1.20 | — |
| 蜂王 | ×1.20 | +2 |
| 进入困难模式 | ×1.25 | +1 |
| 任意机械Boss | ×1.30 | +1 |
| 世纪之花 | ×1.30 | +1 |
| 石巨人 | ×1.20 | — |
| 拜月教邪教徒 | ×1.25 | +2 |
| 月亮领主 | ×1.50 | +4 |

进度全部完成时，武器基础伤害为99，飞剑数量上限为13。实际战斗伤害还受游戏属性、敌人防御等影响。飞剑速度也随进度提高；说明栏显示当前伤害、数量上限和下一阶段提示。

已召唤飞剑保留召唤时的伤害。进度提升后，可先将武器移出背包取消飞剑，再放回背包并重新手持，让所有飞剑使用当前伤害。

飞剑会在附近搜寻敌人，无目标时环绕玩家；每把飞剑使用独立的命中冷却。成长依据世界状态，切换世界后按新世界的进度重新计算。

安装或更新后重启游戏。联机兼容性尚未充分验证。

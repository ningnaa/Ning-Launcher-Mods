# WorldGen Previewer

在世界生成时看着它逐渐成形。游戏自己的地图会随着每一步填充，你可以暂停、逐步前进、重复、跳过或取消生成。

## 界面

| 按钮 | 作用 |
|---|---|
| **步骤** | 显示或隐藏生成步骤列表（地图会变宽）。 |
| **上一步** | 暂停并重新执行上一步。 |
| **继续** | 继续生成。 |
| **暂停** | 在当前步骤之后暂停。 |
| **下一步** | 再执行一步，然后暂停。 |
| **结构** | 显示受保护的结构（绿色和红色）。 |
| **取消** | 停止生成。世界不会被保存。 |

点击按钮即可使用，按住按钮可以查看它的作用。

## 地图

- 地图从左到右一次更新一整列。粉色线条标出正在读取的列。
- 地图以完整分辨率绘制：每个物块是一个像素，和游戏地图一样，边框会贴合世界的形状。
- 用两根手指**捏合**来放大和缩小，放大时拖动可以移动地图。放大时只更新屏幕上的部分，步骤列表会隐藏；完全缩小后它会回来。
- 在地图上**按住**手指，可以看到下方物块的名称。
- 地图下方是生成文字和进度条，使用游戏自己的进度条绘制。
- 世界会在地图最后完整更新一遍之后才完成，所以预览显示的是最终的世界。

## 步骤列表

- 步骤以游戏语言显示，每个名称都能完整显示在一行内。
- 上下拖动列表可以查看所有步骤。
- 点击一个步骤，会继续生成并在它之后暂停。
- 点击步骤旁的 **X** 可以跳过它（再次点击则保留）。
- 白色：尚未执行。灰色：将被跳过。红色：已完成。黄色：已跳过。**(x2)** 表示该步骤执行了两次。

## 设置

**开始时暂停** 会在第一步之后暂停，方便跳过或重复前面的步骤。**地图预览** 用于开启或关闭实时地图。

移植自 jopojelly 的 *WorldGen Previewer*（tModLoader）。

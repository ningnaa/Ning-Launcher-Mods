Raion Light の Murasama Standalone を基にしています。

## ボタン
- **戦技** — チャージ不足なら長押しで溜め、満タンでタップして投擲。飛刀中にもう一度タップで突進斬。
- **終結** — 空中タップで空刃斬、地上タップで震地撃。
- **震地撃** — 独立ボタン。
- **月牙天衝** — 独立ボタン。三段目の薙ぎ払いの後、月牙の刃気を放つ。
- **旋風斬** — 空中で長押しで回転、着地で終了。

## 戦闘
- **薙ぎ払い** — ダメージ倍率は2倍。
- **月牙天衝** — パネルダメージ500%、描画枠が攻撃範囲とともに拡大。
- **次元斬絶** — パネルダメージ1024%、全画面の亀裂。
- **震地撃 / 空刃斬 / 旋風斬 / 突進斬** — 75% / 80% / 60% / 125%。
- すべての判定と刃光が「攻撃範囲」に追従して拡大します。

## 塗装
23種の村正。レシピは統一（銅の短剣 + 鉄/鉛インゴット48 + 落ちた星16、鉄床）。各塗装に専用の配色・UIバー・名前色があり、アイテム説明（ダメージ/会心/速度/ノックバック）も刀身の色に追従します。虹彩は一文字ずつの流れる虹。

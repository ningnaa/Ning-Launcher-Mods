# 人口普查：城镇居民清单

直接扩展背包里的 NPC 居住界面，显示尚未入住的居民头像、入住条件和状态。

- `?`：游戏尚未检查入住条件；`✓`：已满足条件；`X`：尚未满足条件。
- 触摸未入住居民头像查看提示；优先入住的居民会显示“下一位”。
- 触摸已入住居民头像可查看定位箭头，原有房屋查询和分配操作保留。
- 居住列表按可用空间展开；居民较多时沿用游戏原有滚动操作。
- 支持 Bunny JS 城镇 NPC 与 `TownNPCCondition` 条件接口。联机读取房主状态。
- 可以在模组配置中隐藏条件文字、关闭定位箭头或修改箭头颜色。

入住状态随游戏的城镇生成检查更新，并非打开界面就立即重新计算。安装后完全退出并重启游戏。

# Orycto（Alpha）帧率解锁修复版

原作者：vowtz。维护者：柠娜。

提供帧率解锁、平滑移动、光照和特效等配置。本版修复高帧率目标未达到时，世界更新被过度跳过、人物和敌人出现慢动作的问题。更新改为按实际经过时间调度，保留触摸输入和原有配置。

## 如何开启高帧率

1. 在模组配置中开启“解锁帧率”，选择目标帧率；需要主菜单也解锁时，另开启“菜单中启用帧率解锁”。
2. 手机需开启系统高刷新率模式；使用雷电模拟器时，需同时开启模拟器的高帧率选项，并提高模拟器帧率上限。
3. 模组目标、系统显示模式和设备性能共同决定实际帧率。外部上限为 60 帧时，仅把模组目标改为 144 不会得到 144 帧。
4. 安装或更新后完全退出并重新启动游戏。

## 使用限制

高帧率不会加速世界逻辑。此修复不保证所有设备或场景稳定达到目标帧率；大量模组、实体裁剪和平滑处理可能增加开销。出现性能下降时，可逐项关闭平滑和实体裁剪，或禁用本模组后重启。

当前移动运行库中部分 NPC、地图、液体和电路节流选项尚不能正常生效。Alpha 版本，真机及联机兼容性尚未充分验证。保留原 UID、作者署名和配置。

# 裂痕（Split）

一款泰拉瑞亚内容扩展。探索地下雪原的**搁浅冰帆**和地狱上方的**冥域**，用相机收集怪物照片，或试试魔力过载和带架势、蓄力挥击的重近战武器。

## 从哪里开始

在腐化之地或猩红之地找到**暮光行者**，买下召唤道具，夜晚就能挑战**诡影幽灵**。在搁浅冰帆摧毁冰封监牢可挑战**冰封神枪手**。**灾星雷云**可通过夜晚挑战危险人物或让她附身占星家来遇见。进入冥域后，可以释放囚笼中的**帕蜡芬**，也可使用相应召唤物直接挑战。

还可以邀请摄影爱好者入住，把稀有怪物的照片收入相册并领取奖励，和收藏家杰诺希交换物品，或寻找困难模式夜间来访的魔术师。

## 安装与配置

在柠版泰拉启动器的探索目录安装并启用，完全退出后重启游戏。目标游戏运行库为 **301720（Terraria 1.4.5.8.6）**。在游戏的「模组配置」中可调整粒子数量、弹幕光照、拖尾、辉光、震动、闪光、画面对比度和 Boss 镜头聚焦。重近战和部分套装的额外动作可在触控设置中绑定。

本移植版的流程做到**帕蜡芬**。首次启动若在世界中看到裂痕尚未载入的红字提示，请**不要保存，退出后重新进入**，以免丢失模组物品。建议用备份或新存档体验，联机兼容性尚未充分验证。

# 米塔城镇 NPC

将 **Mita NPC 0.0.9** 中的四位 MiSide 城镇居民适配到使用 Bunny Loader 的泰拉瑞亚移动版。

- **米塔（Mita）**：出售游戏卡带回旋镖、胡萝卜；击败全部机械 Boss 后出售旅行戒指；困难模式的血月期间出售变态人的刀。
- **卡皮（Cappie）**：出售可作为时装佩戴的米塔帽子。
- **米拉（Mila）**：出售米拉的书和四本永久手册，分别为近战、远程、魔法或召唤武器增加 10% 伤害。每本手册每个角色只能使用一次。
- **玩家（MiSide）**：出售游戏机、拉面和闹钟。游戏机会召唤发光的苍蝇宠物，闹钟会召唤破损米塔。

白天有合适的空房屋时，居民可以入住。包含完整的巴西葡萄牙语、西班牙语、俄语和英语文本，覆盖物品提示、对话、图鉴条目和幸福度。保留日语/俄语米塔配音、纹理、商店和价格。与原作一样，玩家（MiSide）仅有俄语配音，所有语音均保留录制时的原语言。

## 在移动端使用旅行戒指

将戒指装备到饰品栏。打开**设置 > 控制**，选择自定义布局，点击**编辑**，添加**旅行戒指（Travel Ring）**操作。瞄准光标后点击按钮即可传送。保留原版碰撞检测和 20 秒混沌状态冷却。

## 移植细节

由于 Bunny Loader 没有提供原版城镇 NPC 近战回调，城镇近战攻击由房主端的小型、无需客户端参与的弹幕实现。破损米塔的地面/飞行行为与卡带返回行为使用 JavaScript 实现。在支持的地方保留增益和宠物图标动画；不包含角色预览的上下浮动效果。

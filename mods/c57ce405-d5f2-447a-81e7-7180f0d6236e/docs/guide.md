# QianLongStar · 玩法说明

> 潜龙出渊，厚积薄发。

## 潜龙之星

一件会随在线时间慢慢变强的饰品。佩戴后头顶跟着一颗青蓝色小悬浮星；在线越久，防御、伤害、速度、免伤和仆从/哨兵位越高。

新世界第一次挥动工具时，潜龙之星会自天而降砸中你（扣一颗心），落地后变成可拾取的掉落物；也可在工作台用坠落之星 ×5 + 生命水晶 ×1 合成。

## 五种能力

拿潜龙之星去和 Boss 遗物合成，即可永久解锁一种能力，顺序随意：

| 遗物 | 能力 |
| --- | --- |
| 史莱姆王遗物 | 史莱姆之力 |
| 克苏鲁之眼遗物 | 克苏鲁之力 |
| 蜂王遗物 | 蜂王之力 |
| 世界吞噬者遗物 | 蠕虫之力 |
| 克苏鲁之脑遗物 | 克脑之力 |

## 星族武器

四把武器都需要先佩戴潜龙之星才能在合成列表里看到：

| 武器 | 材料 |
| --- | --- |
| 剑星（近战） | 坠落之星 ×3 + 木头 ×50 |
| 彗尾长弓（远程） | 坠落之星 ×3 + 木头 ×50 |
| 星核法杖（魔法） | 坠落之星 ×3 + 木头 ×50 |
| 坠星召唤杖（召唤） | 坠落之星 ×3 + 木头 ×50 |

## 重铸词缀

武器可由哥布林工匠重铸出本族词缀（吸血、坚盾、追迹、迅疾、闪避、强心、星芒、光芒万丈）。

## 设置

模组设置里可开关头顶悬浮星的显示，以及潜龙之星是否说话；饰品属性与已解锁能力照常生效。

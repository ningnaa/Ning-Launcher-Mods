# 绳索连心

用绳索将所有玩家连在一起，迫使大家互相配合。通过 Bunny Loader 移植到泰拉瑞亚移动版。

## 功能

- 玩家通过绳索串成一条链，绳索拉伸时会把玩家拉向彼此。
- 传送时会带上所有玩家，魔镜同样适用。
- 可选择死亡后的行为：所有玩家一起死亡，或死亡玩家在自己的重生点复活。
- 可配置绳长、拉力和弹性。
- 七种绳索外观：普通绳索、藤蔓、丝绸、蛛网、锁链、Chaotix 或不显示。

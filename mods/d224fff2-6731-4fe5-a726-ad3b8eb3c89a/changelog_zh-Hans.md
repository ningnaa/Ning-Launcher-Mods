# 近战特效修改 1.8.60-r.1

2026-11-26

- 修复慢速武器的攻速加成和按住蓄力键时的平砍节奏。
- 同一角色连续挥砍时，由最新刀光绘制手中的武器。
- 保留命中顿帧的 NPC 槽位清理，以及联机挥砍控制器和刀光同步修复。
- 挥砍、命中、蓄力和挡弹改用泰拉瑞亚内置音效。

需要支持 C# 模组（Format 3）的启动器及 Terraria Build 1720。联机时双方应使用同一模组版本。

WindMind（原版作者）、小绿（手机端移植）、柠版泰拉启动器（移动版汉化与维护）。许可为 MIT。

## 历史更新

## 1.8.60 — 2026-11-26

- **修复基础攻速慢的武器吃不到攻速加成。** 现在刀光的挥砍动画时长和出刀周期用同一个数值严格对齐，所有武器加多少攻速就快多少。
- **修复按住蓄力键平砍会异常加速。** 蓄力控制器会把手臂动画钉成 3 帧，被误当成出刀周期读走了；现在只读出刀时长，蓄力不再干扰平砍节奏。
- **同屏只画手里那一把刀。** 攻速起来后同时存在多条刀光时，只有最新的一条负责画武器，不会再看到几把剑一起挥。

## 1.8.59 — 2026-11-26

这一版修的是挥砍的手感和攻速，刀光外形没有改。

- **攻速加成现在真的生效了。** 以前出刀速度被锁在武器的基础攻速上，攻速堆得越高反而越慢，刀光和剑气也跟着变少；现在加多少攻速就快多少。
- **修复重武器挥到一半就断。** 挥砍时长比刀光寿命长的大剑，以前会扫到一半突然消失，现在收势和淡出都能完整播完。
- **修复连砍时偶尔少一记刀光和伤害。** 同屏刀光满额时，被挤掉的是最老的那一条，不再误删刚出手的那一记。
- **判定改成按当前这一帧的光弧计算。** 刀光扫到的位置都能砍到，不会再出现「看着扫过去了却不掉血」。
- **低端机优化。** 判定范围每帧只算一次，永夜刃光环的星尘清理、刀光设置读取都降了频，连砍时更稳。

装之前请先删掉旧的 1.8.58。

## 1.8.58 — 2026-11-26

- 优化挥砍动作，让体感更加流畅。
- 修复挥砍时武器刀刃朝向不对的问题。

## 1.8.54 — 2026-11-26

这一版只调了刀光的两个滑杆，没有加新特效。

- **屏级玻璃折射和发光没有放进这一版。** 那套还在测，稳定之前不会放出来，这一版每刀还是原来的两次本体绘制。
- **刀光边缘辉光的刻度改了，默认值也调到 100%。** 以前要拉到 20% 左右才是刚好的亮度；现在这一档变成 100%，滑杆拉满就等于旧版的 20%，中段更细腻，不会一下拉过头；不改设置时看到的就是旧版 20% 的亮度。
- **刀光透明度默认改成 20%。** 新装或不改设置的情况下，刀光会比以前更淡，能更清楚看见人物和地面。

## 1.8.51 — 2026-11-24

这一版把永夜刃和刀光的观感收拾干净了。

- **刀光改成玻璃质感。** 以前是一整片均匀的半透明，糊在人物前面像一块紫纱；现在弧身更透、能看见后面的地面和怪物，只保留一圈亮边和一点点厚度，挥过去像一块薄玻璃。
- **永夜刃的紫色光环不再刺眼。** 那圈弹幕的亮度压下去了，原来的大号亮紫球变成暗一档的柔光，不再糊住半个屏幕。
- **永夜刃弹幕周围的闪光粒子删掉了。** 之前弹幕会一路撒细小的高亮星点，画面很碎；现在只留弹幕本身。
- **永夜刃的刀光现在会结算伤害。** 以前它只管好看、不参与伤害，现在刀光本身也能打到怪，和紫环一起生效，实际输出会比原来高一些。

## 1.8.43 — 2026-11-24
- 移除命中时溅出的火星与尘土粒子（不少人觉得这层粒子把画面弄脏、显廉价），只保留刀光爆亮、暴击光斑和击杀断线这几层干净的反馈。

## 1.8.42 — 2026-11-24
- 修复按下攻击后要等半拍才开始挥：上一版把刀光和剑气的触发条件并成了一条，刀光被推迟到挥砍中途才生成，而手臂角度是由刀光驱动的，于是整刀都晚开始。现在刀光回到第 2 帧生成，剑气仍然排在挥到一半的那一帧。
- 刀光持续时间锁回原来的约 26 帧（新增下限），攻速再快也不会一闪就没；收尾淡出也拉长了一点。

## 1.8.41 — 2026-11-24
- 修复朝左挥砍时手臂与刀光反向扫：朝左的人物精灵是镜像的，`itemRotation` 之前用了 `π + heading`，把横扫方向又反了一次；现在改成 `π - heading`，手臂和刀光同向。
- 刀光和手臂改成同一条时间轴：攻速快的剑不会再出现「剑已经收势、刀光还在慢慢扫」的拖影，收刀后只留一小段淡出。
- 自带剑气的剑（泰拉刃这一类）改为挥到中途才放出剑气，弹幕不再抢在抬手的动作前面飞出去。

## 1.8.39 — 2026-11-24
- 修复资源包页「描述」空白、「更新日志」标签消失：描述与日志现在放在包内 `description.md` / `description_zh-Hans.md` / `changelog.md`，不再依赖启动器读不懂的 `localizedDescriptions` 字段。

## 1.8.38 — 2026-11-24

这一版把刀光颜色和「只改剑」的范围收拾了。

- **刀光颜色现在真的跟着武器走。** 以前「跟随武器」这条其实读不到武器颜色，多数剑只会得到一个随机偏色；现在包里内置了 412 把武器的主色，断钢剑是金白、真永夜刃是紫、泰拉刃是青绿，挥出去一眼能对上。蓄力斩的刀光也走同一套颜色。顺手修正了真断钢剑 / 真永夜刃颜色写反的老问题；彩虹猫之刃这类多色武器依然会一路变色。
- **「刀光宽度」拉到 0 不再连剑一起消失。** 以前拉到 0 会连手里的剑都不画，看着像空手在砍；现在只关刀光，剑照常挥，伤害判定一点没变。
- **轻量模式更彻底。** 轻量模式下，蓄力斩蓄满释放时的那下屏幕震动也一并关掉，和「轻量模式关掉屏幕震荡」的说明终于对上了。
- **只对能挥的剑生效。** 长矛（三叉戟、各种戟、鱼叉、武僧长棍等）、回旋镖、悠悠球、链球不再被改成原地挥剑，保持原版突刺 / 投掷 / 甩击动作；永夜刃、真断钢剑、真永夜刃、泰拉刃这类「伤害挂在剑气上」的真近战剑照常有刀光。

## 1.8.34 — 2026-11-23

模组图标回到本包自带的原图标（`icon.png`，128×128），不再用插画。其他一切与 1.8.33 相同。

## 1.8.33 — 2026-11-23

以本包为新基线（版本号从 1.8.31 重新起算，本版记为 1.8.33）。气浪做成可开关，**默认关闭**。

- 设置新增「气浪特效」（`EnableAura`，默认 false）；
- 关闭时：蓄力不再生成 `ChargeAura`、蓄力过程中不画脚下椭圆气场、不画上升气流、蓄满那圈内收白光也不画；
- 打开时：完整走原版气浪（椭圆气场 + 上升气流 + 蓄满冲击环）；
- 刀光、命中顿帧 / 震动 / 推动、蓄力伤害、刀光取色、彩虹相位剑适配都不动。

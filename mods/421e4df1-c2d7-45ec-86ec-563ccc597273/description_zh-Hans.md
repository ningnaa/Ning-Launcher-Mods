# NPC 入住公告

不再错过新居民！每当城镇 NPC 或城镇宠物入住，屏幕顶部都会滑入一个角色扮演游戏风格的横幅，显示其头像、名称和一句俏皮的副标题。

## 横幅样式

- **经典（Classic）**：黑金边框。
- **现代（Modern）**：带动态配色的霓虹边框。
- **腐化、猩红、木质和丛林**：以对应生物群系或材质为主题的横幅。

## 设置

| 设置 | 作用 |
| --- | --- |
| 样式 | 横幅的外观。 |
| 音效 | 魔法提示音、金币、魔力上限、研究、箱子解锁、猩红、敲门、丛林、腐化，或无音效。 |
| 音量 | 入住公告音效的音量。 |
| 持续时间 | 横幅在屏幕上停留的秒数。 |
| 频率 | 首次：每个 NPC 在当前世界首次入住时显示；每次：每次入住都显示；指定次数：最多显示**每个 NPC 上限（Max Per NPC）**所设的次数。 |
| 预览 | 显示测试横幅。 |

每个世界都会记录已经公告过的 NPC。每个原版城镇 NPC 都有专属副标题；其他 NPC 则使用自己的名称和默认副标题。

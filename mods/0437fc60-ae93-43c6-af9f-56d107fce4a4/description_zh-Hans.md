# 星陨遗证

一个把「我们做过的所有东西」打成一包的大合集：**五把武器 + 一个 Boss + 一件成长饰品**。
单独玩的模组都还在，这个包是为了让你不用来回装一大堆，一次开全。

## 里面有什么

### 武器（五把，各自玩法不同）

| 武器 | 类型 | 怎么玩 | 什么时候拿得到 |
|---|---|---|---|
| **神圣天使之剑** | 近战 · 可升级 | 挥砍四段剑技；每 30 次击杀 +1 级（Boss 首杀 +3~8），等级无上限；等级越高伤害、飞剑数量、特效越强 | **肉前就能做**：12 白银锭或钨锭 + 10 坠落之星 + 5 丝绸 @ 铁砧 |
| **黑洞法杖** | 魔法 | 使用键甩出六道弧光、最后汇聚；每轮末尾抛一颗微型黑洞把敌人往里拖。技能键「黑洞·湮灭」：脚下铺法阵、头顶降黑洞，持续吸附撕裂 | 击败**机械骷髅王**后：恐惧之魂 ×8 + 神圣锭 ×12 + 木材 ×20 @ 铁砧 |
| **相位弦弓** | 远程 | 蓄力拉弓、放箭穿透；每射满 24 发触发多重射击（四架相位飞行器射追踪激光）。技能键「轨道激流」：预警圈 → 天降光柱 → 扇形扫射 | 击败**双子魔眼**后：视域之魂 ×8 + 神圣锭 ×12 + 木材 ×20 @ 铁砧 |
| **星轨龙崽** | 召唤 | 召唤小星龙贴身战斗；名额越多、龙越多。技能键「星界降临」召唤成年星龙俯冲、吐息、飞掠、冲撞 | 击败**毁灭者**后：力量之魂 ×8 + 神圣锭 ×12 + 木材 ×20 @ 铁砧 |
| **虚空暗铁鱼炮** | 远程 | 按住连射，六根炮管轮流吐直线虚空弹；每轮吃 6 发子弹。技能键「深渊裂隙弹幕」：撕开裂缝、边吸边倾泻、最后坍缩爆裂 | **机械三王全打**：三种魂各 ×6 + 神圣锭 ×18 @ 铁砧 |

### Boss

**幽影徘徊者** —— 会瞬移、放激光、召唤仆从的影系 Boss。掉落的材料可以合成它的召唤物「暗影幽晶」，让你自己反复叫它出来。
（召唤物配方：神圣锭 ×12 + 暗影之魂 ×10 @ 铁砧，需先击败骷髅王，只能在夜晚使用。）

### 饰品

**星泪钻** —— 会跟着你一起变强的吊坠，四种形态（星泪钻 → 百星凝泪 → 千星泪冕 → 万星终冕）。
每击杀一只敌人，它会随机记住 3 项成长，25 项属性全部**没有上限**，只受游戏本身限制（减伤到 100%、耗蓝到 0 就到顶了）。
戴着就生效，左上角有常驻面板；配置里可以**逐项开关**，关掉只停效果、累计不丢。死亡不掉落、不消失，只把进度清零退回零阶。

## 快捷键

四把武器各有自己的技能键，进游戏后在「设置 → 控制」里能看到并重新摆放；本包已经按原版风格给每把武器配了图标。

## 注意

- 需要 **Bunny Loader / 柠版启动器 0.4.x**（游戏 1.4.5.8.6）。
- 装了这个包之后**不要再同时开**单独版的同名模组（黑洞法杖 / 相位弦弓 / 星轨龙崽 / 虚空暗铁鱼炮 / 星泪钻 / 神圣天使之剑 / 幽影徘徊者），会重复注册。
- 旧存档里如果有单独版模组的物品，换到本包后可能变成 `?`，属于正常现象。

# 东方伙伴：Wild and Horned

以**《东方茨歌仙》（Wild and Horned Hermit）**为灵感的 16 位动态东方伙伴，通过 Bunny Loader 移植到泰拉瑞亚移动版。制作召唤物品后，使用它或放入宠物栏，即可带着一点幻想乡的气息出发冒险。

每位伙伴都会跟随你、轻轻摇摆、眨眼、环顾四周，并做出自己的专属动作。本模组中彼此靠近的伙伴可以发起对话和相互回应。游戏内对话、物品名称、提示和配置标签目前提供**英语与巴西葡萄牙语**。

## 伙伴

| 伙伴 | 性格与动作 |
|---|---|
| 茨木华扇 | 说教、偷吃包子，并在烟雾中变身为鬼。 |
| 星熊勇仪 | 举起酒盏敬酒，开怀大笑。 |
| 小野塚小町 | 假装工作时打盹、打哈欠。 |
| 霍青娥 | 用发簪开洞，露出调皮的笑容。 |
| 圣白莲 | 冥想并转动阳伞。 |
| 高丽野阿吽 | 摇尾巴、吠叫；敌对生物靠近时，光线变成橙色。 |
| 摩多罗隐岐奈 | 打开后门；星光闪烁，夜晚更加明亮。 |
| 本居小铃 | 读书、挥手、轻笑；阅读时灯光变成紫色。 |
| 二岩猯藏 | 扶眼镜、抽烟斗，并变成狸猫茶壶。 |
| 娜兹玲 | 探宝、摆动灵摆，露出得意的神情；附近有宝藏时，光线变成金色。 |
| 洩矢诹访子 | 跳跃、转动铁轮，并在青蛙眼帽子下大笑。 |
| 八坂神奈子 | 展示神社、立起御柱并大笑。 |
| 犬咲夜 | 讨要零食、端茶并摇动耳朵。 |
| 依神紫苑 | 乞讨、释放纯视觉效果的厄运火焰并叹气。 |
| 依神女苑 | 扇风、戴上墨镜并抛硬币。 |
| 犬走椛 | 侦察、下大将棋，并在警戒时举剑。 |

**照明宠物**：阿吽、隐岐奈、小铃、娜兹玲、诹访子、犬咲夜和女苑。她们会悬浮在玩家前方，其他伙伴则悬浮在后方。可以同时装备一位普通宠物和一位照明宠物。

这些伙伴不会造成伤害、破坏方块、偷走钱币或施加厄运。

## 华扇的变身

在暂停菜单中打开**模组配置**，可设置血月是否让华扇保持鬼形态、封印是否会自行松动、变身平均间隔（1–60 分钟）和持续时间（10–300 秒）。默认两个选项均开启，平均间隔为 8 分钟，持续 45 秒。

## 关于移植版

本 Bunny Loader 版本拥有独立的宠物运行机制，不依赖 Touhou Little Friend。每件物品都可通过原有配方获得。原作的“神秘间隙”商人属于 Touhou Little Friend；如果兼容的 Bunny Loader 移植版提供 `touhoupets/YukariPortal` 以及 `Shop` / `Shop2` 商店，这两个商店就可以加入本模组物品。

tModLoader 版 Touhou Little Friend、Pet House 和 Pet House Stories 不能由 Bunny Loader 直接加载。本独立移植版没有包含与模组外角色的对话，也不包含 Pet House 住房功能。保留了原作四个 `Mod.Call` 查询命令，供未来的 Bunny Loader 伙伴模组使用。
